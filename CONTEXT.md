# Python Fieldnotes

Practice alongside an existing Python course.

## Language

**Skill unit**: A focused explanation and short exercises for one connected Python idea.
_Avoid_: mastery level

**Challenge**: A program combining several skill units, open to attempt at any time.
_Avoid_: locked level

**Variation**: A related exercise that changes what the learner must do, offering another independent attempt.
_Avoid_: renamed duplicate

**Recorded progress**: Evidence of attempts, checks, assistance and self-reported independence; it does not certify understanding.
_Avoid_: mastery score

## Relationships

- Skill units support several challenges.
- Challenges link to prerequisite exercises and variations.
- Recorded progress belongs to individual exercises and attempts.
